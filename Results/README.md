# Results

This directory contains the patches generated by each tool, organized by platform (`Linux/`, `Android/`) and tool (`SemPort`, `Fixmorph`, `PortGPT`, `TSBPORT`), with one patch file per CVE (`<CVE-ID>.patch`).

**Note:** When testing certain CVEs, some tools may fail to port the patch and produce no patch output. As a result, the number of patches stored here is smaller than the total number of CVEs actually tested.
